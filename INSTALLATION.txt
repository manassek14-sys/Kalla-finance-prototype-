KALLA FINANCE — MODULE DE TABLEAUX DE RÉPARTITION

CONTENU DU DOSSIER
- allocations.js : module des tableaux personnalisables.
- sw.js : service worker avec cache v3 incluant allocations.js.

INSTALLATION SUR GITHUB (branche main)

1. Ajouter allocations.js
   - Ouvrir le dépôt KALLA Finance.
   - Add file > Create new file.
   - Nom exact : allocations.js
   - Coller le contenu du fichier allocations.js.
   - Commit changes.

2. Modifier index.html
   - Ouvrir index.html et appuyer sur Edit.
   - En bas du fichier, repérer :
       <script src="app.js"></script>
   - Ajouter juste après cette ligne :
       <script src="allocations.js"></script>
   - Ne supprimer aucune autre ligne.
   - Commit changes.

3. Remplacer sw.js
   - Ouvrir sw.js, remplacer tout son contenu par le fichier sw.js fourni.
   - Commit changes.

4. Attendre le déploiement GitHub Pages, puis recharger le site.

CE QUE LE MODULE AJOUTE
- Quatre tableaux de départ : bénéfices, fonds d’investissement, trésorerie et budget personnel.
- Création illimitée de tableaux supplémentaires.
- Modification des titres, montants, catégories et pourcentages.
- Ajout et suppression de catégories et de tableaux.
- Calcul automatique des montants par catégorie.
- Graphique circulaire et contrôle du total à 100 %.

PROTECTION DES DONNÉES
Le module utilise une nouvelle clé locale : kalla-finance-allocations-v1.
Il ne supprime, ne réinitialise et ne modifie pas les opérations existantes stockées par KALLA Finance.
Les tableaux sont enregistrés sur le navigateur de l'appareil où ils sont créés.

IMPORTANT
Les nouveaux tableaux sont autonomes : leurs modifications ne changent pas les anciennes rubriques de réglages existantes. Le montant de référence de chaque tableau est modifiable indépendamment.
